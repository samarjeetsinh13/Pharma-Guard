# =====================================================================
# PHARMA GUARD - SUITABILITY RULES  (hand-built demo database)
# =====================================================================
# Format (one rule per line, columns separated by the | character):
#   illness name | medicine name | verdict | reason
#
# verdict must be exactly one of:
#   SUITABLE      - commonly used for this illness
#   CAUTION       - may be used, but needs care / a doctor's judgement
#   NOT_SUITABLE  - does not treat this illness or can make it worse
#
# If an illness + medicine pair is NOT listed here, the program reports
# UNKNOWN ("no rule in the demo knowledge base") - it never guesses.
#
# Illness and medicine names must exist in illnesses.txt / medicines.txt.
# EDUCATIONAL DEMO DATA ONLY - NOT MEDICAL ADVICE.
# =====================================================================

# ---- I001 Fever ----
Fever|Paracetamol|SUITABLE|First-choice fever reducer for most adults and children (dose by weight/age).
Fever|Ibuprofen|SUITABLE|Reduces fever and body ache; take with food.
Fever|Aspirin|CAUTION|Avoid in children and teenagers (risk of Reye's syndrome); adults only with care.
Fever|Amoxicillin|NOT_SUITABLE|An antibiotic does not treat fever itself; only useful if a bacterial infection is confirmed.
Fever|Metformin|NOT_SUITABLE|Antidiabetic medicine with no effect on fever.
Fever|Atorvastatin|NOT_SUITABLE|Cholesterol medicine with no effect on fever.

# ---- I002 Headache ----
Headache|Paracetamol|SUITABLE|Common first-line pain reliever for tension-type headache.
Headache|Ibuprofen|SUITABLE|Effective for mild to moderate headache; take with food.
Headache|Aspirin|SUITABLE|Effective for occasional headache in adults.
Headache|Diclofenac|CAUTION|Stronger NSAID with stomach and heart risks; keep for cases a doctor advises.
Headache|Tramadol|NOT_SUITABLE|Opioids are not advised for routine headache (dependence and rebound-headache risk).
Headache|Amoxicillin|NOT_SUITABLE|Antibiotic; does not treat headache.

# ---- I005 Urinary Tract Infection ----
Urinary Tract Infection|Ciprofloxacin|SUITABLE|Commonly used antibiotic for UTI; follow urine-culture and local guidance.
Urinary Tract Infection|Amoxicillin|CAUTION|Resistance is common; use only if the lab report shows it will work.
Urinary Tract Infection|Azithromycin|NOT_SUITABLE|Does not reach useful levels in urine, so it is a poor choice for UTI.
Urinary Tract Infection|Paracetamol|SUITABLE|Relieves pain and fever while the antibiotic works.
Urinary Tract Infection|Ibuprofen|CAUTION|Can strain the kidneys; avoid if kidney problems or dehydration.

# ---- I006 Type 2 Diabetes ----
Type 2 Diabetes|Metformin|SUITABLE|First-line medicine to lower blood sugar.
Type 2 Diabetes|Glimepiride|SUITABLE|Lowers blood sugar; watch for low-sugar (hypoglycemia) episodes.
Type 2 Diabetes|Losartan|SUITABLE|Protects the kidneys in diabetes with high blood pressure.
Type 2 Diabetes|Atorvastatin|SUITABLE|Supportive: lowers heart-disease risk, which is higher in diabetes.
Type 2 Diabetes|Prednisolone|CAUTION|Steroids raise blood sugar and can undo diabetes control.
Type 2 Diabetes|Ibuprofen|CAUTION|NSAIDs can harm the kidneys, which are already at risk in diabetes.
